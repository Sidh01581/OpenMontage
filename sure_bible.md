# SURE. — YouTube Short Plan

Draft for approval (Nov 24, 2026). Same Story Short format as WE NEED TO TALK. (9:16, ~45 s, comedy twist).

## Overview

**SURE.** is a ~44-second vertical Short. Theo can't say no. Every "Sure!" slaps a sticky note on him and spawns another copy of a grinning little creature called Sure. By night he's buried in notes and favors, so he practices saying no. The next morning he finally says it, proudly, to the one offer he should have taken: a day off.

**YouTube title:** When you can't say no 😅 #peoplepleaser

### Format (unchanged from WE NEED TO TALK.)

## Sound

**No music** (same sitcom cold-open approach as WE NEED TO TALK.). Every "Sure!" lands with the same sticky-note slap + pop, pitched up one step each time, so the yes-spiral becomes a rising musical joke. The "NO!" gets a record scratch and true silence.

| Time | Sound bed | Feel |
| --- | --- | --- |
| 0:00–0:07 | Office hum, slap + pop, Sure's tiny squeak-nod | Cheerful |
| 0:07–0:20 | Slap + pop rising in pitch each yes; phone ring; calendar cascade; swarm chant | Escalating, silly |
| 0:20–0:31 | Night hum, keyboard, whispering swarm, then near-silence for practice | Tired |
| 0:31–0:35 | Soft morning office | Calm |
| 0:35–0:38 | Record scratch, TRUE SILENCE, footsteps walking away | The wrong no |
| 0:42–0:44 | Tiny squeak, "Su—", hard cut to silence | Punchline |
